# خارطة تنفيذ البيزنس الكاملة

الخطة تحول الشاشات الحالية إلى HRMS قابل للاعتماد. التنفيذ عمودي: قاعدة بيانات → صلاحيات → transaction/API → شاشة → تقارير → اختبار، مع الحفاظ على التصميم.

| المرحلة | المجال | المخرجات التجارية | شرط الخروج |
|---|---|---|---|
| P0 | الأساس المؤسسي | tenant/company، العضويات، RBAC وfield-scope، audit/event، effective dating، idempotency | عزل وصلاحيات وتعارض على staging |
| P1 | الموظفون والهيكل | شركات/فروع/أقسام، ملف موظف، تاريخ وظيفي، مستندات، CSV متحقق | لا سجل بلا tenant أو تاريخ مصدر |
| P2 | الطلبات والموافقات | أنواع ومسارات متعددة المستويات، تفويض، SLA، سجل قرار immutable | قرار server-side ومنع اعتماد الذات والتكرار |
| P3 | الوقت والغياب | شفتات، جداول، بصمة، حضور، تأخير/إضافي، إجازات وأرصدة | عبور اليوم/المنطقة الزمنية واختبار كشف الرواتب |
| P4 | الرواتب | عناصر استحقاق/خصم، دورات، إغلاق، قيود، بنك، country packs مراجعة | لا نسب أو قوانين مخترعة وتسوية قابلة للتدقيق |
| P5 | السلف ونهاية الخدمة | دفتر صرف/سداد، موافقات، أرصدة، مخصص/طلب نهاية خدمة | كل مبلغ بوحدات صغرى ومصدر حركة |
| P6 | التقارير والحوكمة | تقارير، تصدير آمن، قوالب استيراد، audit viewer، مؤشرات جودة | رفض البيانات الناقصة وعدم إخفاء اليتيم |

لا تُغلق أي مرحلة بمجرد اكتمال الواجهة؛ يلزم اختبار قاعدة بيانات وصلاحيات وحالات فشل وUAT وخطة rollback/forward-fix.
