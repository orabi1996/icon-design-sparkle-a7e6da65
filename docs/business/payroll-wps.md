# PROMPT 7 — نظام الرواتب ودورات المسير وحماية الأجور (Payroll + Payroll Period + WPS)

## 1. نظرة عامة والمعمارية

تم تحويل مسيرات الرواتب (`payroll_runs`) من مجرد أرشيف وحسابات شكلية في واجهة المستخدم إلى **Payroll Domain مؤسسي متكامل**، حيث تتم جميع العمليات الحسابية حصريًا داخل الخادم بدقة وحتمية مطلقة (Deterministic & Server-side)، مع حفظ لقطات المدخلات وصيغ الاحتساب (Snapshotting & Versioning)، وحماية المسيرات المغلقة ضد أي تعديل عبر Triggers في قاعدة البيانات، وتوليد ملف حماية الأجور (WPS) الفعلي المعتمد من مؤسسة النقد / وزارة الموارد البشرية.

---

## 2. كيانات النطاق وقاعدة البيانات (`20260918070000_payroll_domain_wps.sql`)

| الجدول / الكيان | الوصف |
|---|---|
| `payroll_periods` | دورات المسير (`year`, `month`, `period_type`, `status`) مع قيد فريد يمنع تكرار مسير لنفس الفترة |
| `payroll_runs` | مسيرات الرواتب مع حفظ لقطة الإقفال `locked_snapshot` والإجماليات المعتمدة ومفتاح التجزئة |
| `payroll_salary_components` | كتالوج بنود الراتب (الأساسي، البدلات، الإضافي، خصومات التأخير، الغياب، أقساط السلف، والتأمينات) |
| `payroll_inputs` | لقطة المدخلات المحفوظة لكل موظف موثقة بـ `source`, `source_id`, `source_version` |
| `payroll_results` | النتائج المحسوبة لكل موظف مع لقطة الحساب التفصيلية `calculation_snapshot` |
| `payroll_adjustments` | تسويات ما بعد الإغلاق وفروقات المسيرات اللاحقة (Delta Adjustments) |
| `payroll_payment_batches` | دفعات الصرف والتحويل البنكي |
| `payroll_bank_files` | ملفات حماية الأجور (WPS) غير القابلة للتعديل والمحمية بتوقيع التجزئة الرقمي المشفر `SHA-256` |

### حماية المسيرات المقفلة (Triggers):
- `trg_protect_locked_payroll_run`: يمنع تعديل الإجماليات المالية أو حذف أي مسير بحالة `locked`, `posted`, `paid`, أو `closed`.
- `trg_protect_locked_payroll_results`: يمنع تعديل أو حذف نتائج أي مسير مقفل ويلزم إنشاء حركة تسوية مستقلة.
- `payroll_bank_files_immutable`: يمنع أي تعديل أو حذف لملفات البنوك الصادرة.

## 3. محرك الحسابات الحتمي وحزمة المملكة (Saudi GOSI Country Pack)

### أ. الراتب والبدلات:
- الراتب الأساسي (`BASIC`)
- بدل السكن (`HOUSING`)
- بدل النقل (`TRANSPORT`)
- البدلات الأخرى والعمل الإضافي (`OVERTIME`)
- إجمالي الراتب (Gross) = الأساسي + جميع البدلات + الإضافي + الإضافات اليدوية.

### ب. التأمينات الاجتماعية (GOSI):
- **الموظف السعودي:** استقطاع **9.75%** (9% تقاعد + 0.75% ساند) على (الأساسي + السكن) بحد أقصى **45,000 ريال**.
- **مساهمة الشركة (للسعودي):** **11.75%** (9% تقاعد + 0.75% ساند + 2% أخطار مهنية).
- **الموظف غير السعودي:** **0%** استقطاع على الموظف، و **2%** أخطار مهنية تدفعها الشركة.

### ج. حماية سقف الاستقطاعات (50% Rule):
- لا يتجاوز إجمالي الاستقطاعات **50%** من إجمالي الراتب النظامي.
- في حال كان قسط السلفة يتجاوز القدرة الاستيعابية المتبقية، يتم حجز واقتطاع الجزء المسموح فقط وتسجيل إشعار في لقطة الحساب `loanCapped: true`.

---

## 4. مطابقة وتدقيق الإجماليات (Totals Reconciliation)

المحرك يضمن مطابقة تامة:
$$\text{Total Gross} - \text{Total Deductions} = \text{Total Net}$$
بدقة الهللة (0.01) مع استبعاد الكسر الصفري (-0) في جميع العمليات المالية.

## 5. محول ملفات حماية الأجور (WPS Bank File Adapter)

### أ. التحقق والتدقيق قبل التوليد:
- التحقق من الآيبان السعودي (24 خانة تبدأ بـ SA).
- التحقق من رقم الهوية أو الإقامة (10 أرقام تبدأ بـ 1 أو 2).
- التحقق من أن صافي الراتب موجب (> 0).

### ب. هيكل ملف SAMA WPS القياسي:
- **سجل الرأس (SCR):**
  `SCR|PayerIBAN|BankCode|ValueDate|BatchRef|MolEstId|RecordCount|TotalAmount|Currency`
- **سجل الموظف التفصيلي (EDR):**
  `EDR|EmpNo|NationalId|EmpName|EmpIBAN|BankCode|Basic|Housing|Other|Deductions|NetSalary`

### ج. التوقيع الرقمي (SHA-256):
كل ملف يصدر يتم حساب تجزئة `SHA-256` كاملة لمحتواه وتخزينها في قاعدة البيانات وعرضها في واجهة المستخدم لضمان سلامة الملف وعدم التلاعب به.

## 6. مؤشرات الجودة والأداء (Gate Matrix)

| البوابة المطلوبة بـ PROMPT 7 | الحالة | آلية التحقق |
|---|---|---|
| احتساب حتمي ومتكرر (Reproducible) | ✅ محقق | اختبار `is reproducible: same inputs yield identical results` |
| المسير المقفل لا يمكن تعديله | ✅ محقق | Triggers `trg_protect_locked_payroll_run` و `trg_protect_locked_payroll_results` |
| منع تكرار الدورة (Duplicate Period Blocked) | ✅ محقق | قيد فريد `UNIQUE (company_id, year, month, period_type)` |
| تسويات ما بعد الإغلاق بإصدارات | ✅ محقق | جدول `payroll_adjustments` |
| مطابقة الإجماليات (Totals Reconciled) | ✅ محقق | دالة `reconcilePayrollTotals` بنسبة تطابق 100% |
| فحص وتوليد ملف حماية الأجور WPS | ✅ محقق | دوال `validateWpsRecord` و `generateWpsBankFile` مع SHA-256 |
| اختبار أداء على حجم واقعي | ✅ محقق | احتساب ومطابقة 500 موظف في **10.9 مللي ثانية** |
| جميع الاختبارات PASS | ✅ محقق | **201/201 اختبار ناجح بنسبة 100%** |
